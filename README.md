# HOROLOGY — Luxury Swiss Watch Landing Page

A premium, handcrafted e-commerce landing page for a luxury Swiss watch brand.  
Built with **vanilla HTML, CSS, and JavaScript** — no frameworks, no dependencies.

> 🔗 **[Live Demo →](https://SaucesCode.github.io/horology-landing/)**

---

## ✨ Features

- **Cinematic Full-Viewport Hero** — Parallax background with gradient text typography
- **Animated Number Counters** — Stats bar that counts up on scroll (IntersectionObserver)
- **Scroll Reveal Animations** — Elements gracefully fade in as you scroll, Apple-style
- **Working Shopping Cart** — Add/remove items, quantity controls, localStorage persistence
- **Sliding Cart Drawer** — Hardware-accelerated 60fps slide-in with blurred overlay
- **Spotlight Feature Section** — Full-width product showcase with technical specifications
- **Customer Testimonials** — Social proof cards with star ratings
- **Masonry Image Gallery** — Lifestyle imagery with hover zoom effects
- **Newsletter Signup** — Email capture form in the footer
- **Responsive Design** — Mobile-first, works on all screen sizes
- **SEO Optimized** — Open Graph, Twitter Cards, JSON-LD structured data, semantic HTML

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Structure | HTML5 (Semantic) |
| Styling | Vanilla CSS (Custom Properties / Design Tokens) |
| Logic | Vanilla JavaScript (ES6+) |
| Fonts | Google Fonts (Playfair Display, Inter) |
| Images | Unsplash (Royalty-free) |
| Hosting | GitHub Pages |
